## English

## About this repository

This repository is a personal AI space where I collect, build, test, and document different resources related to artificial intelligence.

Here you will find prompts, mini apps, automations, experiments, templates, workflows, and other projects designed to explore how AI can help with productivity, creativity, development, learning, and problem-solving.

The goal of this repository is not only to store useful AI resources, but also to show how AI can be used as a real working companion: helping to write, code, organize ideas, build tools, generate content, and improve everyday digital workflows.
